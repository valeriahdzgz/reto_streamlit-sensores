# Panel de Depuración y Visualización de Sensores

Aplicación desarrollada en Streamlit para visualizar y analizar métricas de sensores industriales en tiempo real.

## Archivos del Proyecto
- app.py: Código principal de la interfaz en Streamlit.
- datos_sensores.csv: Conjunto de datos con las mediciones de los sensores.
- requirements.txt: Dependencias necesarias para ejecutar la aplicación.
